02The One Gap: git-hooks.nix

Current pre-commit state

AGENTS.md records: “Pre-commit hooks use buildflow. Hooks are not set as executable and are skipped.” So pre-commit is effectively non-functional today. The standard stack recommends cachix/git-hooks.nix for declarative, nix-managed hooks that actually run.

Recommended addition (optional, non-breaking) Add git-hooks.nix as an input and wire it into devShells.default via config.pre-commit.installationScript. Suggested hooks: treefmt (auto-format on commit), gofumpt, end-of-file-fixer, and a cqrs-lint wrapper. Caveat already documented in AGENTS.md: the formatter steps must exclude vendor/ or they OOM on the modernc.org/sqlite sources within the 2-minute hook budget — the treefmt vendor/** exclusion is already set.

03Optional Plan (if the user wants git-hooks.nix)

1

Add the git-hooks input

Add git-hooks = { url = "github:cachix/git-hooks.nix"; inputs.nixpkgs.follows = "nixpkgs"; }; to inputs, and imports = [ inputs.treefmt-nix.flakeModule inputs.git-hooks.flakeModule ];.

2

Configure hooks

Enable treefmt, end-of-file-fixer, trim-trailing-whitespace, and a custom cqrs-lint hook in pre-commit.settings. Reuse the existing treefmt config so formatting stays single-source.

3

Wire into devShell + verify

Add config.pre-commit.installationScript to devShells.default. Run nix develop then pre-commit install. Confirm nix flake check --no-build still passes. Vendor exclusion is already handled by treefmt settings.

Known Non-Migration Items (tracked elsewhere)

  • vendorHash = null + committed vendor/ — forced by go-cqrs-lite being private. Not a flake-migration issue. Tracked in TODO_LIST.md; the clean fix is to make go-cqrs-lite public, then switch to a real vendorHash and drop vendor/.
  • GOEXPERIMENT=jsonv2 wiring — required by go-cqrs-lite v4 in Go 1.26. Already correctly wired in three places (preBuild export, GOFLAGS in devShells, .golangci.yml build-tags). Not a migration concern.
Bottom line No migration required — the flake is already on the standard stack and passes nix flake check --no-build. The only optional improvement is adopting git-hooks.nix to make pre-commit hooks actually run (today they are skipped). That is a small additive change, not a migration.
