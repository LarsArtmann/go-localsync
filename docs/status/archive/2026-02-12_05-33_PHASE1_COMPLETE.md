## Executive Summary

go-localsync is a Go library and CLI for syncing GitHub User Events to SQLite/Turso database. Phase 1 (Foundation) is **feature-complete** with a working data pipeline: Auth → API → Transform → Store.

The project follows the 1% effort = 51% value principle, delivering a minimal viable sync tool with:

- Pure Go SQLite driver (no CGO)
- Type-safe SQL via sqlc
- Idempotent event storage
- Incremental sync support

### Current Structure

```

├── cmd/gh-sync/          # CLI entrypoint
├── internal/
│   ├── database/         # DB connection (handwritten)
│   └── db/               # sqlc generated (DO NOT EDIT)
├── pkg/
│   ├── github/           # GitHub API client
│   ├── storage/          # Storage interface + SQLite impl
│   └── sync/             # Sync orchestration
└── sql/
    ├── schema/           # DDL
    └── queries/          # sqlc queries
```

### Data Flow

```
GitHub API → pkg/github.Client.FetchEvents()
           → convertEvent() [COUPLING ISSUE]
           → pkg/storage.Event
           → pkg/sync.Syncer.Sync()
           → pkg/storage.SQLiteStorage.UpsertEvent()
           → SQLite DB
```

### Recommended Improvements

1. **Decouple types**: Create `pkg/event/types.go` with domain types
2. **Use interfaces**: `pkg/github` should return its own type, sync layer converts
3. **Add errors package**: `pkg/errors/errors.go` with typed errors

## G) CLI REFERENCE

### Available Flags

| Flag           | Default                                 | Description            |
| -------------- | --------------------------------------- | ---------------------- |
| `-token`       | `$GITHUB_TOKEN`                         | GitHub PAT             |
| `-user`        | (required)                              | Username to sync       |
| `-db`          | `~/.local/share/go-localsync/events.db` | Database path          |
| `-pages`       | 10                                      | Max pages to fetch     |
| `-incremental` | true                                    | Only fetch new events  |
| `-stats`       | false                                   | Show DB stats and exit |
| `-verbose`     | false                                   | Debug logging          |
| `-version`     | false                                   | Show version           |

### Example Commands

```bash
# Basic sync
gh-sync -user octocat

# Verbose with custom pages
gh-sync -user octocat -verbose -pages 20

# Show stats
gh-sync -stats

# Custom database location
gh-sync -user octocat -db /path/to/events.db
```
